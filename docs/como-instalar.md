# Como instalar e usar o DenDen

O DenDen serve para você assistir à tela e ao som do computador de um amigo no **Windows** enquanto vocês conversam no Discord. Não precisa instalar nada complicado.

## 1. Baixar o programa

1. Entre na página de **Releases** do projeto no GitHub (peça o link para o dono do grupo).
2. Na versão mais recente, clique no arquivo `.zip` para baixar (por exemplo, `denden-windows.zip`).

## 2. Extrair a pasta inteira

1. Vá até a sua pasta de **Downloads**, clique com o botão direito no arquivo `.zip` baixado e escolha **Extrair tudo...** (ou use programas como WinRAR / 7-Zip).
2. **Importante:** não abra o programa de dentro do `.zip` e não tire o `denden.exe` de dentro da pasta. Todos os arquivos precisam ficar juntos na mesma pasta para funcionar.

## 3. Abrir o DenDen (aviso do Windows)

1. Abra a pasta que você extraiu e dê dois cliques em **`denden.exe`**.
2. Na primeira vez, o Windows pode mostrar uma tela azul dizendo *"O Windows protegeu o computador"*. Isso acontece porque é um programa caseiro feito entre amigos.
3. Clique em **Mais informações** (logo abaixo do texto) e depois no botão **Executar assim mesmo**.

## 4. Configurar na primeira vez

Na primeira vez que abrir, você verá a tela **DenDen — Configurar**:

1. **Endereço do servidor:** cole o endereço começando com `https://` que o dono do grupo te mandou.
2. **Sua chave:** cole a sua chave pessoal.
3. Deixe o campo **Chave de administrador** em branco.
4. *(Dica)* Marque a opção **Não abaixar o volume dos outros programas** para o Windows não reduzir o som do jogo e do Discord.
5. Clique em **Salvar**.

## 5. Assistir a uma transmissão

1. Vá até a aba **Assistir**.
2. Digite ou cole o **Código da sala** que o seu amigo te passou (por exemplo, `K7P-92Q`).
3. Clique em **Assistir** e pronto! A tela e o som do jogo dele vão aparecer para você.
